# ABCDE Trainer — نظام تدريب التقييم الأولي للمريض

مشروع رقم 10: Smart Emergency Triage & Patient Assessment.
محاكي ويب بـ Python (Streamlit) بيدرّب المستخدم على تقييم المريض بنظام ABCDE وتصنيف درجة الاستعجال.

> ⚠️ للتعليم فقط، بيانات تجريبية، وليس أداة تشخيص طبي. في الطوارئ الحقيقية اتصل بالإسعاف 123.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

لتفعيل التغذية الراجعة بالـ LLM (اختياري):
```bash
export ANTHROPIC_API_KEY="..."      # على ويندوز: set ANTHROPIC_API_KEY=...
```

## هيكل المشروع
| ملف | الدور |
|---|---|
| `scenarios.py` | 5 سيناريوهات (اختناق، نزيف، سكتة، هبوط سكر، التواء) بخطوات A–E وخيارات صح/غلط وشرح علمي |
| `model.py` | توليد بيانات اصطناعية + Decision Tree لتصنيف (مستقر / متوسط / عاجل) |
| `app.py` | واجهة Streamlit: الخطوات، العداد، الدرجة، تصنيف ML، تغذية راجعة |

## الذكاء الاصطناعي في المشروع
1. **ML:** Decision Tree (scikit-learn) مدرّب على علامات حيوية اصطناعية (تنفس، أكسجين، نبض، ضغط، وعي، حرارة) بقواعد مبسّطة مستوحاة من NEWS2 + ضوضاء 3%.
2. **LLM (اختياري):** تغذية راجعة مخصصة على أخطاء الطالب.
3. **تقييم:** درجة من 100 (ترتيب الخطوات 20، التصرفات 50، التصنيف 20، قرار الإسعاف 10، خصم تأخير).

## إضافات ممكنة للتطوير
- توليد سيناريوهات جديدة بالـ LLM (بصيغة JSON بنفس هيكل `scenarios.py`).
- علامات حيوية بتتغير مع الوقت لو المستخدم اتأخر.
- لوحة نتائج للمتدربين (قاعدة بيانات SQLite).
